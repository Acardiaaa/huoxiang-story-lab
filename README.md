# 藿香正气虚拟仿真研习

研究生教学 VN 网页，静态独立部署版本。

## GitHub Pages 发布

1. 将本文件和 docs 文件夹上传到 GitHub 仓库的 main 分支。
2. 打开仓库 Settings → Pages。
3. Source 选择 Deploy from a branch。
4. Branch 选择 main，文件夹选择 /docs，点击 Save。
5. 等待 GitHub 提供实际访问地址后再分享给学生。

所有运行资源均包含在 docs 内，不依赖 Google Fonts 或 chatgpt.site。
姓名、学号、成绩和进度保存在访问者浏览器本机；支持导出记录，没有中央成绩数据库。更换域名不会自动迁移原站进度。

该包未包含教师评分详案、原始文献、下载资料或任何学生记录。网页本身含自动评分规则。

GitHub Pages 的国内网络可达性仍需在使用者网络上实测。
